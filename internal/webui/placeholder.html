UI not built — run make ui

This gos3 binary was built without the embedded web UI. The S3 API and the admin API work normally; only the browser interface is missing.

To embed the UI, build it and rebuild the binary from the repository root:

make build      # = make ui + make build-go

Alternatively run the UI standalone (cd web && pnpm install && pnpm dev) and connect it to this server.
